# Ebay Homepage Locators

This file lists the important locators discovered for https://www.ebay.com.

- search_box: Global Search Input - Type into this input field to main search textbox located in the header for entering product keywords.
- search_button: Global Search Button - Click this button to button next to the search box that triggers the product search.
- cart_button: Cart (Shopping Cart) Link - Click this link to link in the header that opens the shopping cart overview.
- sign_in_button: Sign In Link - Click this link to header link that opens the sign‑in modal or redirects to the login page.
- account_button: My eBay Account Link - Click this link to header link that navigates to the user's account dashboard (my ebay).
- deals_link: Deals Link - Click this link to top navigation link that leads to the ebay deals page.
- navigation_menu: Main Category Navigation Menu - Open this menu to horizontal menu under the header containing primary category links (e.g., electronics, fashion).
- product_links: Featured Product Links - Click this link to links for individual product tiles displayed on the homepage or search results.
