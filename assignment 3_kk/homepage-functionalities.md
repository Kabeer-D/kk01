# Flipkart Homepage Functionalities

This file lists the important user flows identified for https://www.flipkart.com.

- Product Search: User searches for a product using the main search box and initiates the search.
- User Sign‑In: Existing user logs into their Flipkart account via the sign‑in button.
- Add Product to Cart: User selects a product from search or category results and adds it to the shopping cart.
- View Cart and Proceed to Checkout: User opens the cart to review items and initiates the checkout process.
- Browse Daily Deals: User navigates to the deals/offers section to view discounted products.
- Navigate Through Top Categories: User uses the top navigation menu to explore different product categories.
- Access Account Options: After signing in, user opens the account dropdown to manage profile, orders, or logout.
