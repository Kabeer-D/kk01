# Github Homepage Locators

This file lists the important locators discovered for https://www.github.com.

- search_box: Search Input - Main search text box located in the header where users type product keywords.
- search_button: Search Button - Button next to the search box that triggers the product search.
- cart_button: Cart Button - Link/button that opens the shopping cart overview.
- sign_in_button: Sign In Link - Link in the top right corner that opens the sign‑in dialog for unauthenticated users.
- account_button: Account Menu - Dropdown that appears after signing in, providing access to account settings, orders, etc.
- deals_link: Deals Link - Navigation link that directs users to the eBay Deals page.
- navigation_menu: Top Category Navigation - Horizontal menu containing main category links (e.g., Electronics, Fashion, Motors).
