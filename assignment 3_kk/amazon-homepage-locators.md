# Amazon Homepage Locators

This file lists the important locators discovered for https://www.amazon.com.

- search_box: Search Input - Type into this input field to main search text box located in the header where users type product keywords.
- search_button: Search Button - Click this button to button next to the search box that triggers the product search.
- cart_button: Cart Button - Click this button to link/button that opens the shopping cart overview.
- sign_in_button: Sign In Link - Click this link to link in the top right corner that opens the sign‑in dialog for unauthenticated users.
- account_button: Account Menu - Click this menu to dropdown that appears after signing in, providing access to account settings, orders, etc.
- deals_link: Deals Link - Click this link to navigation link that directs users to the ebay deals page.
- navigation_menu: Top Category Navigation - Open this menu to horizontal menu containing main category links (e.g., electronics, fashion, motors).
- product_links: Product Links - Click this element to start the related action
