# QA Multi-Agent Workflow

This project runs a multi-agent QA workflow using Groq models.

## Run locally

1. Create a virtual environment
2. Install dependencies
3. Set GROQ_API_KEY
4. Run the script

See HOW_TO_RUN.md for full instructions.

## GitHub note

Before pushing to GitHub:
- do not include chat logs or local API keys
- keep .env local and ignored
- use .gitignore to avoid committing Python cache and virtual environment files
